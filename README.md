# V4ME: Voice for Mother Earth Humanitarian Foundation

Next.js 16 + Tailwind CSS 4 + Framer Motion, styled with the EcoSphere palette.
Blog powered by Sanity (editor at `/studio`), donations by Paystack.

**First time? Read [SETUP.md](./SETUP.md)** to connect the blog and payments.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Deploy

Push to a new GitHub repo and import it on Vercel, then add the environment variables listed in `.env.example` (see SETUP.md).
